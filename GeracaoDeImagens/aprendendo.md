# 📘 **SEÇÃO 2 — Seu Plano de Estudo (Direto ao ponto)**

### **🎯 Duração: 7 dias de prática leve (10–15 min/dia)**

## **📅 Dia 1 — Aprender o “framework” de prompts**

Você aprende o **esqueleto universal** de um bom prompt:

### **Prompt Universal (estrutura)**

Você vai decorar isso:

```
Create an image in the style of [ESTILO],
showing [IDEIA PRINCIPAL],
representing [CONCEITO QUE EU QUERO ESTUDAR],
emphasizing [A PARTE MAIS IMPORTANTE],
avoiding [COISAS QUE NÃO QUERO].
The image should be [ESTILO DE COMPOSIÇÃO].
```

Exemplo:

> Create an image in the style of clean conceptual illustration,
> showing a golden spark appearing when a bright side meets a dark side,
> representing the XOR idea,
> emphasizing the contrast where difference creates activation,
> avoiding any use of numbers or binary digits.
> Composition minimal and symbolic.

A partir daqui você só preenche os espaços.

---

## **📅 Dia 2 — Como controlar TEXTO dentro da imagem**

Você aprende:

**Regra essencial:**

> Texto deve ser pedido *no fim* do prompt, isolado, e com aspas duplas.

Por exemplo:

```
Include the expression "1 ^ 0" in the top left corner,
written exactly as shown, do not alter the characters.
```

E quando o modelo erra:

> “Correct the symbol: use '^' not 'x'. Keep the rest identical.”

# 📘 **SEÇÃO 3 — Seu Conjunto de Templates por Finalidade**

Aqui estão os **templates iniciais**, já otimizados para você:

---

## **🎯 Template 1 — Mnemônico abstrato para lógica**

```
Create a symbolic illustration in a clean didactic style,
representing the concept of [CONCEITO],
using a metaphor based on [METÁFORA],
emphasizing [PONTO ESSENCIAL].
Avoid text except for the expression "[TEXTO]",
which must appear exactly as written.
Minimal background, high contrast, functional for memorization.
```

---

## **🎯 Template 2 — Ilustração conceitual estilo surrealista simbólico**

```
Create a surreal symbolic painting,
showing [IDEIA],
where [ELEMENTOS] represent [CONCEITO].
Use strong contrast between light and shadow.
Composition focused and uncluttered,
artistic but didactic.
Avoid any elements unrelated to the concept.
```

---

## **🎯 Template 3 — Yin-Yang conceitual**

```
Create a conceptual Yin-Yang illustration,

Minimalist composition, high contrast,
didactic and symbolic.
```
